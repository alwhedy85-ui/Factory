# خط الفليكسيبل

تطبيق أندرويد لنفس حاسبة وصلات الفليكسيبل: الاستهلاك، الغطاء، العزل، زمن التصنيع، قائمة المواد، التكاليف، ورصيد الخامات.

ملف الـ APK يتبني تلقائيًا على GitHub Actions عند كل رفع على فرع `main`.

بعد ما يخلّص البناء:

1. افتح تبويب **Actions** في الريبو.
2. افتح آخر تشغيل ناجح باسم **Build APK**.
3. نزّل الـ artifact باسم `flex-duct-apk`.
4. فك الضغط وثبّت `app-debug.apk` على الموبايل (اسمح بالتثبيت من مصادر غير معروفة).

النسخة دي للتجربة (توقيع debug)، مش نسخة متجر بلاي.
